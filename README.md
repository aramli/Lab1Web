=========Jawaban Soal Praktikum==========

#### 1. Apa fungsi deklarasi <!DOCTYPE html> pada dokumen HTML?
**Jawaban:**  
Deklarasi ini memberi tahu browser bahwa dokumen menggunakan HTML5, sehingga browser menampilkan halaman sesuai standar terbaru.
#### 2. Apa perbedaan antara tag, elemen, dan atribut pada HTML?
**Jawaban:**  
Tag adalah penanda (misalnya `<p>`), elemen adalah keseluruhan struktur (tag + isi), sedangkan atribut adalah informasi tambahan pada tag (misalnya `href` pada `<a>`).
#### 3. Apa perbedaan `<p>` dengan `<br>`? Jelaskan penggunaannya.
**Jawaban:**  
`<p>` digunakan untuk membuat paragraf baru, sedangkan `<br>` hanya memindahkan teks ke baris berikutnya tanpa membuat paragraf.
#### 4. Apa fungsi atribut href pada tag `<a>`?
**Jawaban:**  
Atribut `href` menentukan alamat tujuan hyperlink yang akan dibuka ketika link diklik.
#### 5. Apa perbedaan hyperlink ke halaman internal dengan hyperlink ke website eksternal?
**Jawaban:**  
Hyperlink internal mengarah ke halaman lain dalam satu website, sedangkan hyperlink eksternal mengarah ke website di luar domain tersebut.
#### 6. Apa fungsi atribut src dan alt pada tag `<img>`?
**Jawaban:**  
`src` menentukan lokasi file gambar, sedangkan `alt` memberikan teks alternatif jika gambar gagal ditampilkan.
#### 7. Apa perbedaan penggunaan `<ul>` dan `<ol>`?
**Jawaban:**  
`<ul>` digunakan untuk daftar tak berurutan (bullet), sedangkan `<ol>` digunakan untuk daftar berurutan (angka/nomor).
#### 8. Apa yang terjadi jika path gambar pada atribut src salah?
**Jawaban:**  
Jika path salah, gambar tidak akan muncul dan browser hanya menampilkan teks alternatif (`alt`) jika ada.
#### 9. Mengapa struktur heading h1 sampai h6 perlu digunakan secara terstruktur?
**Jawaban:**  
Heading h1–h6 menjaga hierarki konten agar lebih rapi, mudah dibaca, dan membantu SEO serta aksesibilitas.
#### 10. Apa fungsi komentar `<!-- ... -->` dalam kode HTML?
**Jawaban:**  
Komentar digunakan untuk menambahkan catatan pada kode agar lebih mudah dipahami, dan tidak ditampilkan di browser.
